## 資料與驗收邊界

完整名單快照只包含抽獎模型既有欄位；不收集 API key、token、密碼或聊天室訊息。瀏覽器會在抽選前檢查暫存容量；伺服器單筆快照請求上限為 16 MiB。較大名單需要改用適合的大型暫存與持久化儲存方案後再支援。

這次只跑相關 API integration test 類別及 4 個相關 Playwright spec，沒有宣稱整個 API 測試專案或所有 E2E 都通過。正式站部署版本仍未知，需由維護者在正式部署版本驗收。#295/#313 的遠端 Issue 狀態不因本 PR 自動變更；此 PR 不包含合併或部署。
