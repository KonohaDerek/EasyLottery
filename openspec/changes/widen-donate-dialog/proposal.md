## Why

Donate 活動編輯表單包含活動設定、時間、動畫與獎項欄位，現有 Dialog 寬度不足，讓欄位與表頭難以同時閱讀。

## What Changes

- 將 Donate 活動新增與編輯 Dialog 在桌面視窗的寬度調整為至少 75%。
- 在窄螢幕維持安全邊距與既有捲動行為，避免內容超出視窗。

## Capabilities

### New Capabilities

- `donate-activity-editor-layout`: Donate 活動編輯 Dialog 的可讀版面規範。

### Modified Capabilities

- 無。

## Impact

- 受影響專案：EasyLotteryWasm 的 Donate 活動頁面樣式與 Dialog 標記。
