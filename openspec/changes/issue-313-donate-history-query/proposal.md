# Issue #313：核心抽獎歷史、Donate 紀錄與導覽

## 背景

Issue #295 的主程式已在 Vue 管理列提供四個可收合群組，但使用者提供的窄版截圖仍是平鋪清單；截圖同時顯示一個 active 項目與游標停留項目，兩者目前使用相同高亮，容易被看成兩個 active。正式站公開入口目前只能到管理員 Passkey 登入頁，部署 commit、bundle 與管理頁載入路徑未確認。

Issue #313 的盤點顯示 Donate 抽獎紀錄已持久化在結果儲存文件，但沒有管理員查詢入口。戳戳樂／轉盤已有活動結果頁，審計也有獨立頁面。一般核心抽獎仍只存在本頁記憶體，沒有可靠保存契約。

## 目標

- 讓日常抽獎／活動、互動、模板、結果紀錄、OBS 素材、平台支付與系統安全各自成群。
- 讓 hover/focus 與唯一的目前頁面標示在視覺上不同。
- 新增管理員限定、唯讀的 Donate 抽獎紀錄列表，支援日期、活動、結果類型、關鍵字與分頁。
- 為核心抽獎結果建立 UUID 穩定識別、完整抽獎當下參與籤及既有平台帳號識別快照、版本化規則快照、冪等保存及管理員歷史查詢；保存回應不明時用原 UUID 查詢，不再抽一次。
- 在「結果與紀錄」群組呈現活動結果、核心抽獎紀錄、Donate 抽獎紀錄及操作審計。

## 範圍

- Vue AdminLayout 的導覽分類、active route 判定與 focus/hover 樣式。
- 核心抽獎結果的 UUID、完整 immutable 名單／規則快照、冪等保存、未知保存狀態對帳及管理員分頁歷史查詢。
- GET /api/donate-lottery-draw-records 的管理員唯讀查詢 DTO 與篩選／分頁。
- 核心抽獎與 Donate 紀錄 Vue 頁面與路由。
- 合成資料單元、API 權限／冪等／對帳／篩選／分頁測試，以及瀏覽器窄版與桌面導覽／紀錄狀態檢查。
- 記錄正式站版本未知，並維持 #295、#313 的追蹤狀態，不更新遠端 issue。

## 非目標與邊界

- 不實作 #306 聊天公告或 #307 核心抽獎 OBS overlay；兩者仍依賴核心持久化狀態與穩定識別。
- 不回填或捏造本功能啟用前沒有持久化的核心抽獎結果。
- 不新增寫入、付款、真實抽獎、外部公告或 OBS 分享功能。
- 不回傳付款外部識別碼、捐款訊息、金流憑證或管理 token；不查詢正式資料。
- 不登入正式站、不合併或部署；PR 僅供程式碼審查，Issue 驗收狀態仍由維護者追蹤。

## 驗收

- 導覽群組可用原生鍵盤 disclosure 展開／收合；直接載入或重新整理受保護路由時，正確群組展開且只標示一個 active route。
- hover、focus 與 active 有不同的可見樣式；窄版選單可捲動且選路後關閉。
- Donate 紀錄 API 僅允許管理員、唯讀、最多回傳 100 筆一頁；搜尋可使用活動名稱/ID、贊助者名稱及獎項名稱。
- 已刪除活動的紀錄仍可查，活動顯示「已刪除活動 #ID」；空、載入、無權限及讀取錯誤各有明確呈現。
- 所有測試只使用合成紀錄；不從目前名單回填核心歷史啟用前結果。

## 風險與回復

Donate 名稱和金額屬於管理資料，查詢端點必須沿用既有管理 session 驗證，DTO 最小化欄位且不輸出付款識別碼、私人訊息或 payment method。若查詢實際需要更廣資料或權限，停止擴大並另行設計。回復方式為還原本 change 的 Vue/API/test 檔案；不需資料遷移。
