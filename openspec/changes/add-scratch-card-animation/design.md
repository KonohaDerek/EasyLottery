## Context

Donate OBS 已以 CSS 動畫提供四種抽獎場景，並將結果資料保留到揭曉階段。刮刮樂可使用同一結果資料，在動畫階段將文字置於銀漆覆蓋層下方，不需要新的 API 或抽獎邏輯。

## Goals / Non-Goals

**Goals:** 提供可保存的刮刮樂動畫選項，讓動畫依設定秒數自動刮除並露出一次結果，再由既有揭曉階段呈現結果。

**Non-Goals:** 不實作滑鼠或觸控手動刮除，也不改變獎項機率、圖片或結果保存方式。

## Decisions

- 在 `DonateLotteryAnimation` 末端增加列舉值，保留既有 YAML 數值相容性。
- 使用 CSS mask、掃刮軌跡與銀漆碎屑動畫表現自動刮除；`--draw-duration` 控制完整動畫長度。
- 將結果文字放在卡片底層，僅在動畫接近結束時露出；揭曉階段仍由共用結果 UI 再顯示名稱。

## Risks / Trade-offs

- [部分瀏覽器 CSS mask 支援差異] → 同時以銀漆層透明度淡出作為可讀的 fallback。
- [長獎項名稱] → 限制字級並啟用文字換行，避免卡片溢出。
